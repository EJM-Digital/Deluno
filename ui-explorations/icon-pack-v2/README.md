# Deluno Specific Icon Pack V2

Exploration assets for:

- More specific app feature/navigation icons.
- Windows app icon choices.
- Browser/favicon choices.
- Taskbar and tray icon choices.

## App Icon SVGs

- `deluno-route-primary.svg` - broad Deluno routing/orchestration mark.
- `deluno-library-route.svg` - library/folder-specific mark.
- `deluno-plan-compass.svg` - Media Plan and recipe/planning mark.
- `deluno-signal-orbit.svg` - connections/indexer/download-client mark.
- `deluno-minimal-favicon.svg` - simplified browser/favicon candidate.
- `deluno-taskbar-mono.svg` - high-contrast taskbar/tray candidate.

## Recommendation

Use `deluno-route-primary.svg` for the Windows app icon, then simplify to `deluno-minimal-favicon.svg` for browser/favicon and `deluno-taskbar-mono.svg` for tray/high-contrast contexts.

The feature icons should be implemented as lucide-style line icons in the product, not full app-logo marks. Their shape should describe the item directly: dashboard, libraries, Media Plans, quality, size, release scoring, destinations, connections, queue, imports, automation, activity, calendar, settings, movies, TV, and search.
